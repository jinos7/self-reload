⚠️ 도메인 승인 필요 (auth/unauthorized-domain)

현재 접속 중인 도메인이 Firebase 승인된 도메인에 등록되어 있지 않아 Google 로그인이 차단되었습니다.

현재 접속 도메인:
  1. Firebase 콘솔 (self-reload) 접속
  2. 빌드 → Authentication → 설정(Settings) 클릭
  3. 승인된 도메인 → 도메인 추가에 위 복사한 주소를 붙여넣기
💡 도메인 등록 없이 바로 쓰시려면? 아래 [동기화 코드로 바로 연결]을 누르면 PC와 모바일에서 동일한 비밀 코드로 즉시 실시간 동기화할 수 있습니다.
